# 阶段计划与验收 v0.5

当前业务目标：能力与素材积累开始服务持续内容生产。实现方案由执行模型独立提出；本文件约束使用结果，不是逐文件施工单。实际状态见 STATUS。

## 前置收尾与推进方式

共享状态与接续已有实现；最新 R2/R5 修复的代码审查、15 项测试、lint、构建已独立通过。部署和完整网页恢复仍待验，不能写成全部线上通过。保留这条交付收尾线，但不再让内部固定演示替代业务推进：补部署与网页复验，同时开展下面已授权的新阶段。

执行模型先核对仓库、已有改动及实际 Easel/H3 环境，简短说明用户从哪里开始、结束能得到什么、哪些依赖可用及取舍，随后连续实现和验证。常规选择自行处理；缺外部环境时完成可行部分，明确模拟/交换包/真实集成的区别。

## 当前阶段：素材库、可复用方法与两轮内容生产

真实场景：用户随手收下一篇资料、一个文件或想法，也能选择现有项目成果；在能力板块找到素材与已有做法，组合成一次内容行动。Codex 根据事实提出适合受众的内容角度，Easel 承接运营和图文制作；视频可交给 AutoDL 上的 H3。成品回到同一行动，发布及反馈关联具体版本。第二次行动实际使用第一次的素材、方法或判断，留下新成品。

不要求所有内容都来自开发项目。生活需求、教程、工具比较、外部发现均可进入；不要直接把开发总结改写成宣传稿，也不要编造体验、节省时间或效果。

### 1. 能力板块必须有素材库

能力板块提供“素材库”和“方法与工具”两个关联视角，不必复制成两套孤立系统。

- 链接、文本、文件之一即可保存；允许在网页直接粘贴、记想法、上传，也允许 Codex 通过同一业务接口录入。不强制项目、分类、标签或完整能力档案。
- 可收纳文章、帖子、教程、图片、视频、提示词、Skill、工作流、个人经验及既有成果。收下的 Skill/软件不自动安装或执行。
- 原始来源与文件保留。Codex 可补标题、摘要、建议标签；未读取、读取失败和已读取明确区分。只保存链接不能标为已保存全文/文件。
- 支持浏览、搜索/筛选、适合类型的预览、渐进整理及从多份素材发起内容行动。详情可见来源、可选收藏理由、关联方法/项目、实际用于哪些内容。
- “已使用”不是“用完”：素材可被多次引用。Easel/H3 的脚本、图片、片段、成片可回收再用，不重复人工录入或复制状态。

### 2. 方法与工具要能被实际调用

用途、输入材料、做法（提示词/Skill/步骤/工具入口）、依赖条件、成品案例、限制及版本是语义要求，字段由执行模型精简。先从“实践转内容”“图文制作运营”“视频制作运营”等当前需要开始，不硬编码为只能有三种能力。

工具安装成功不等于方法有效。区分待尝试、已跑通、已复用，自述与实测分开，结论指向对应版本与证据。方法更新不改写旧成果引用，也不自动继承旧验证结论。

### 3. 接入现有生产工具

| 位置 | 职责 |
| --- | --- |
| MYOPC | 素材、方法、项目、行动、成品与结果的共同记录及业务入口 |
| Codex | 理解积累、提出内容角度、组织创作任务、执行连接和分析反馈 |
| Easel | 账号定位、选题策划、图文制作、平台适配、审阅、发布及可用的运营分析 |
| AutoDL H3 | 承接视频生成任务；实际输出是片段还是完整成片，由现有工作流核定 |

Easel 是用户已选用的运营系统，可以使用其自带 Agent/OpenClaw；MYOPC 不因此再造聊天 Agent，也不复制其账号中心、内容日历、编辑器。Easel 负责账号级运营经验，MYOPC 保存跨项目可复用方法与对应证据。

交给 Easel 的创作任务包含受众/目的、内容角度、事实与素材引用、不能夸大的边界、关联项目及成果版本。标题、脚本、分镜可交给 Easel 发挥，不把 MYOPC 文本机械润色当作内容转化。

Easel 已考察的入口包括文件/附件、技能和会话、产物、发布与分析 API；接入前核对实际安装版本，不把应用内部 API 当成稳定外部承诺。参考 [仓库](https://github.com/ZJU-REAL/Easel)、[接口实现](https://github.com/ZJU-REAL/Easel/blob/main/web/app.py)。

H3 的具体项目、启动命令、输入输出、费用和访问方式尚未由仓库证据确认，必须核对用户实际使用环境，不猜测模型/API。已有算力在授权范围内使用；本阶段目标不自动授权购买或启动收费实例。片段还需后续制作，完整成片可进入检查和发布。

### 4. 联动与循环验收

- 从无项目、无分类的链接/文本/真实测试文件完成收纳；跨环境可找回，预览可用，失败来源诚实显示。
- 选多份素材与一个方法版本形成行动，可看出为什么适合当前受众；不需要用户再抄一套背景。
- 图文经过实际 Easel 制作并回收成品；视频核对 H3 接口后完成一次可行的任务交接与产物回收。不可访问时保留待验，不以普通文件上传伪称 H3 已运行。
- 外部任务保留关联、输入版本、最后已知状态、结果和失败原因；提交成功不等于生成成功，已生成不等于已发布。超时先核对任务，不盲目重复生成或发布。
- 发布由 Easel 承接并沿用账号实际流程；具体对外发布仍需相应授权。锁定发布版本，区分已提交、已核实发布、链接待补；没有真实链接或回执不得造假。
- 回收实际可得的反馈，注明平台、内容、时间、来源；缺失不是零。先显式导入/必要查询，不建设全平台数据采集系统。
- 第二次行动引用第一轮的具体素材/方法/反馈及判断，并实际产出新内容。仅复制、关联或写总结不能通过；保留有效方法同样允许，须说明依据。一条作品表现不能证明因果或稳定收益。
- 没有发布授权或平台条件时，完成成品及生产复用，市场反馈单列待验；已授权且环境可用时继续完成，不人为停在导出。
- 验证文件和关联的持久化、备份恢复、外部失败重试、旧版引用不漂移。前端浏览器走真实故事，技术夹具明确标记。

## 交付标准与边界

交付包含实现、必要验证、清晰页面和可复查证据，提交推送并核验远程；在已有授权范围部署。文档区分代码、API、网页、外部执行及业务结果，不因为新计划写完而宣称功能完成。

缺少环境权限不整轮停等，先完成其余部分并留下确切缺口。低频方向判断、高密度自主执行，不重新依赖特别详细的提示词。既有版本、幂等、冲突、共享状态和数据保护要求延续。

暂不建设 GPU 调度系统、通用工作流引擎、自动模型派工、全量个人知识图谱或第二套运营后台。未来根据实际生产量、失败和反馈扩展。S1 的生产复用与 S2 的外部价值证据可在本阶段逐步积累，分别判定；收入不是首轮通过条件。
