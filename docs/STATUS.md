## 当前生产部署

MYOPC 已迁移到新的私人云端工作节点并完成日常使用验收，当前结论为 `READY FOR DAILY OPC USE`。

生产代码来自 GitHub `main`，当前已部署提交为 `1e12206ff35898fa2c2aa9f838839f1eb870702a`。本地开发副本曾落后一个提交，后续开发开始前必须先同步远端；旧服务器没有 Git 元数据，仅保留历史运行版本标记，不再视为代码事实源。

新服务器当前采用宿主机 Node.js + `systemd` 运行，而不是 Docker Compose。原因是服务器访问 Docker Hub 拉取 Node 基础镜像不稳定；项目已在 Node.js `v22.23.2` 上完成 `npm run build`、正式启动、写入、应用重启和服务器重启恢复验证。服务 `myopc.service` 已设为开机自启且当前 active。

应用只监听 Tailscale 私网接口的 `3010` 端口。两台个人电脑均已通过独立 SSH Key 和同一 Tailnet 接入服务器，PC2 已实际通过 Tailscale IP 与 MagicDNS 打开 MYOPC；公网应用端口未开放。仓库不记录真实服务器公网地址、Tailnet 域名、密钥或凭据。

生产目录按代码与数据分离：

- 源码：`/opt/apps/src/opc`
- 持久化数据：`/opt/data/opc`
- 备份：`/opt/backups/opc`
- 运行服务：`myopc.service`

当前 OPC 常驻内存约 54 MB，整机 4 核、约 3.6 GiB RAM，迁移验收时仍有约 3.1 GiB 可用内存，Swap 未成为常态依赖。

迁移后的已核对数据包括：

旧服务器当前标记为 `LEGACY / FALLBACK`，原服务和数据仍保留，但不应与新服务器同时产生新的业务写入。待新实例稳定使用一段时间后，可进一步转为停止运行但保留备份的冷备用。

## 已有基础

稳定项目身份、行动/成果版本/反馈/决策、共享 HTTP 接续、幂等、过期提交保护与一致性备份已有实现。能力板块首个业务切片已完成：

- 网页和 REST API 可保存链接、文本、文件元信息及不超过 2 MB 的私有文件；支持浏览、关键词搜索、来源/正文/文件预览入口及读取状态。
- 方法按不可变版本保存，新版本保留前一版本与方法族引用；旧行动继续指向原版本。
- 可选择多份素材和一个方法版本创建行动；行动上下文回读具体素材和方法版本，使用次数来自同一关联表。
- 写入沿用 `client_request_id` 幂等保护，迁移回填旧行动的单素材关系。
- 素材文件随 SQLite 备份保存到同名 `.assets` 目录并在隔离恢复时复原，避免只有数据库元信息而丢文件。
