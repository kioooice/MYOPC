# 产品说明

MYOPC 是个人能力与一人公司经营工作台。它把素材、方法、项目、行动、成果和反馈连接起来，让一次工作的积累能用于下一次工作。

本文件描述产品方向；已有功能见 [STATUS.md](STATUS.md)，当前开发范围见 [TASKS.md](../TASKS.md)。

## 使用场景

- 看到文章、教程、工具或灵感，先保存链接、文本或文件，后续再整理。
- 从资料和实践中整理可复用的方法，保留步骤、适用条件、来源和版本。
- 为一个项目或小尝试确定目标，记录所用素材和方法，保存实际产物。
- 查看和修改稿件、图片、视频或工具成果，反馈对应具体版本。
- 在后续工作中找到上次的素材、方法和反馈，决定复用、调整或停止。

不要求先建项目或填写完整能力档案。学习和尝试不必立即变现，真实经营结果单独记录。

## 主要视角

| 视角 | 关注内容 |
| --- | --- |
| 总览 | 正在做什么、最新成果、待处理事项和下一步 |
| 素材与能力 | 轻量收纳、搜索、预览、方法与来源、使用关系 |
| 项目与行动 | 目标、说明、相关位置、进度和实际结果 |
| 成果与反馈 | 内容版本、修改意见、采用记录和后续决策 |

这些视角共用记录，不重复维护多套状态。保持中文界面和低负担操作，逐步补充信息。

## Easel 与其他工具

当前 OPC 和 Easel 在本地分别部署。Easel 承担内容制作和运营，MYOPC 保存素材、跨项目方法及成果关系。
先通过实际可用的手动方式交接，再依据重复操作开发连接；自动交接属于待开发能力。
视频制作等外部能力按任务选用，AutoDL H3 是已有方向，不是每轮开发的必选依赖。

MYOPC 不需要内置模型才能运行，也不承担通用 Agent 调度。用户可以直接操作网页，开发和执行工具的分工按任务选择。

## 记录原则

- 收藏、整理、实际使用与验证是不同事实。
- 方法和成果的新版本保留旧版本引用。
- 采用不等于发布，生成内容不等于取得市场效果。
- 示例与真实结果区分；没有反馈时不编造数据。
- 项目身份独立于电脑路径；多台电脑各自的本地数据不会自动同步。

产品设计随使用反馈调整；循环复用是长期目标，不作为每个普通功能交付的强制关卡。
