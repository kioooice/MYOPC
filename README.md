# MYOPC

个人能力应用与 OPC（一人公司）经营工作台。

MYOPC 连接发现、个人积累、行动、成果和反馈，使下一次行动用上前一次的经验。Codex 承担主要规划、执行与分析，工作台提供持续可用的素材、方法、项目和成果视图。

**当前状态：共享状态与接续基础已有实现；最新两项修复的代码复验通过，部署及完整网页重试待验。**
**当前业务阶段：能力素材库与两轮真实内容生产。新增内容属于规划，尚未实现。**

## 当前生产方向

| 部分 | 分工 |
| --- | --- |
| MYOPC | 素材收纳、方法版本、项目行动、成品和结果关联 |
| Codex | 理解积累，提出有依据的内容角度，组织创作任务和分析反馈 |
| Easel | 账号定位、图文制作、平台适配、审阅、发布及运营 |
| AutoDL H3 | 按用户现有工作流承担视频生成，具体输入输出与连接需核对 |

能力板块同时包含素材库、方法与工具。链接、文本或文件即可收下，不强制项目、分类或完整档案；网页与 Codex 使用同一业务服务。支持多素材创作、原始来源、类型适配预览和使用记录。已使用不等于用完，脚本、图片和成片也可以回收再用。

Easel 的参考实现见 [ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel)。允许使用其自带 Agent，MYOPC 不复制聊天、账号管理或内容编辑器；也不建设 GPU 调度系统。

第一轮产出真实内容，第二轮实际使用前一轮素材、方法或判断并产出新成品。只归档或写复盘不算复用。图文、视频、工具实践和生活发现都可进入，不强制所有选题来自开发项目。

## 已有使用基础

已有行动、项目、成果版本、反馈、决策、共享接口、幂等、冲突保护及一致性备份。新增素材和生产联动的实际完成程度始终以 STATUS 为准。

环境基线为 Node.js 24+、npm 11+。Windows 可使用 start.bat 或 start.ps1。手动开发可运行：

~~~sh
npm install
npm run dev
~~~

使用 MYOPC_DATA_DIR 指定私有数据目录。共享服务连接通过私有配置提供 MYOPC_BASE_URL、MYOPC_USERNAME 和 MYOPC_PASSWORD；不将真实连接地址和凭据写入公开说明。

通用客户端支持 context、start、draft、feedback、revise、decision，内容支持文件输入。写入用稳定的 --request-id，结果不确定时复用原请求编号和载荷；修订必须声明所基于的版本。具体已实现接口与示例见 scripts/continuity-client.ts 和应用路由；架构文档的候选接口不等于全部实现。

~~~sh
npm test
npm run lint
npm run build
~~~

备份、校验、隔离恢复入口为 npm run db:backup、npm run db:verify、npm run db:restore，参数见 scripts/db-maintenance.ts。SQLite WAL 下不能只复制运行中的主数据库文件。多端通过同一共享业务服务读写，不把各端独立数据库当作自动同步。

## 真实性与范围

收藏不等于方法验证；生成不等于采用或发布；接口成功不代表已核实平台上线；内部反馈不冒充市场结果。授权发布和收费资源按实际范围执行，不从新规划推导任意发布或购买权限。

当前为可修订规划 v0.5。近阶段围绕真实使用展开，远期按证据扩展，不靠长提示词逐项指挥，也不把全部想法一次性做成平台模块。

仓库只保存代码、通用方法与脱敏交接。真实稿件、未发布媒体、账号信息、经营数据和运行配置保存在私有存储。
